## 🚀 Overview
This project moves beyond simple SQL queries into the realm of **Database Programming**. It implements complex business rules for an Art Gallery system using **Oracle PL/SQL**, focusing on data integrity, automated price adjustments, and sophisticated error handling.

## ✨ Key Technical Features
* **Complex Control Structures:** Blocks that calculate dynamic price adjustments based on sales vs. estimates.
* **Stored Procedures & Functions:** Modular code for artist portfolio management and statistical calculations.
* **Advanced Cursors & Collections:** Use of `SYS_REFCURSOR` and nested tables to process batches of records efficiently.
* **Database Triggers:** Automated audit logs and constraints that prevent invalid data entry (e.g., preventing duplicate exhibition entries).
* **Exception Handling:** Robust `EXCEPTION` blocks to ensure the system remains stable during data conflicts.

## 🛠 Tech Stack
* **Language:** PL/SQL (Oracle)
* **Environment:** Oracle SQL Developer
* **Architecture:** Procedural Database Logic

## 📂 Project Structure
* `Procedures_Functions.sql`: Stored logic for gallery operations.
* `Triggers_Security.sql`: Automation and data integrity rules.
* `SGBD_Documentation.docx`: Full academic report with logic flowcharts.
